# Contribuir

Las contribuciones deben mantener la trazabilidad de datos y supuestos.

1. Abra un issue que describa el cambio propuesto.
2. No publique datos personales, coordenadas de hogares ni microdatos restringidos.
3. Registre URL, institución responsable, fecha de descarga y licencia de cada fuente.
4. Mantenga intactos los archivos crudos; transforme los datos mediante código.
5. Añada pruebas para cambios en limpieza, indicadores o rutas.
6. Ejecute `ruff check .` y `pytest` antes de enviar un cambio.

Las correcciones de nombres o coordenadas de instituciones deben indicar evidencia y nivel de confianza.
